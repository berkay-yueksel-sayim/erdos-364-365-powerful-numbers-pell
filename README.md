# Consecutive powerful numbers, Pell equations, and Erdős problems #364 and #365

A positive integer is powerful if every prime that divides it divides it at least twice. Pairs of consecutive powerful numbers exist in abundance, but no three consecutive powerful numbers are known; Erdős asked whether they exist. This repository holds a collected volume and its three parts.

> **Status: preprint, prototype release (v1.0).** The data deposit and the code behind the computed numbers are being cleaned and translated and will be added to this repository soon, probably within about a week. Until then the repository contains the PDFs only.
